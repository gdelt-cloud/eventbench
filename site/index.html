Limits

Criticisms we expect

UCDP is the wrong denominator

It is independent of every service, public, and counts single deaths, so it is hard for everyone. Indepaz, SATP and five non-conflict lists are added, and every panel is reported on its own.

UCDP is human-built and not real time

UCDP researchers code each event by hand from news, NGO and local sources; the Candidate release comes about a month after the events and the final dataset once a year. That makes it an independent yardstick, and a hard one.

Web search was not given a fair chance

Each web service was asked in the query style its own documentation recommends, in its own news or date-window mode. A deeper-search configuration and a lookup mode, where web search is strongest, come next.

An AI judged it

Claude reviewers, a different model family from the one GDELT Cloud uses for coding. Records shuffled, sources hidden. A second reviewer re-judged 40 incidents: κ = 0.83. The pooled run had two jurors from different labs judging every record, and a third model audited a sample blind. Every verdict is published.

Searching after the fact

Web indexes gain follow-up coverage with hindsight, so web figures are, if anything, high. Timeliness is not measured.

Why are the web services anonymous?

Their terms restrict publishing named comparisons. The scores describe how this kind of tool behaves on monitoring questions. To compare a service you use, plug it in: any web search service works through a small adapter.

What is web search + LLM?

The pipeline a developer builds to imitate an event feed: run the search, hand the results page to an LLM, get back de-duplicated records with date, place, parties, deaths and sources. It cannot find what the search did not return.

GDELT Cloud depends on how you query it

It does, which is why release 2026.11's conflict figures are withdrawn: they searched around each incident and gave GDELT Cloud alone a second look. Every figure here comes from country-week queries any customer would send, reviewed like everyone else's. Its first page of each list alone returned 31% of lethal conflict incidents, every page 32%.

Reproduce

Run it yourself

Python 3.10+, standard library only, and a GDELT Cloud API key. Any web search service plugs in through a small adapter, and any event list through a CSV; AGENTS.md walks a person or a coding agent through it. Every paid call is reserved in a local ledger and stops at your cap.

python -m unittest discover tests
python bench.py refs
python bench.py cloud
python bench.py gdelt
python bench.py check-adapter --adapter adapters/my_search.py
python bench.py web --adapter adapters/my_search.py --label my_search --max-usd 5
python bench.py eventlist --file my_events.csv --label my_list
python bench.py packets
python bench.py score
python report.py --results run/occurrences.csv
